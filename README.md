# 🔗 ZiplyURL

A simple and fast URL shortening application built with **Next.js**, **MongoDB**, and **API Routes**.  
Users can generate custom short URLs and instantly redirect to the original link.

##  Features

- Create custom short URLs (e.g., `/github`)
- Instant redirection using dynamic routes
- MongoDB database for storing URL mappings
- Clean and responsive UI
- Works locally and can be deployed to Netlify or Vercel
